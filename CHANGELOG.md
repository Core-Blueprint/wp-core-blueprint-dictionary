# Changelog

## 0.1.0-rc1

- Initial Core Blueprint Dictionary release candidate.
- Added native `cb_dictionary` post type with Gutenberg and normal WordPress content support.
- Added configurable Dictionary URL base with safe one-time rewrite refresh.
- Added user-managed Dictionary Categories and Dictionary Tags.
- Added machine-owned `0-9` + `A-Z` Alphabet taxonomy with automatic title-based assignment.
- Added five registered dictionary metadata fields and WP-native editing UI.
- Added builder-agnostic list, search, alphabet, category and metadata shortcodes.
- Added Core Blueprint Base dependency gate, PageRegistry settings, ExtensionRegistry health and canonical Governance events.
- Added source conformance and canonical release packaging tooling.
